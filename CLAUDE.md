# CLAUDE.md

## Important rule: how to make changes

**Never edit `src/data/exercises.js` directly** for exercise changes (adding/removing/changing exercises, sets, reps).

Always do it in this order:

1. Update `plan.md` first
2. Update `src/data/exercises.js` to match (with correct weighttraining.guide images and the exercise `key`, `sets`, `default` weight, and `even` step)

This keeps the two files in sync and avoids mistakes.

## Source of Images

- Images come from weighttraining.guide
- Training images may be similar to the exercise, no need to perfectly match, https://weighttraining.guide/?s=test search page can be used when finding the new images.
